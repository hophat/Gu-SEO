fix: v1.14.2 — Brand DNA provider dispatch drift + retired Gemini model

"Không đọc được website" was misleading: the scrape succeeded, the AI call
failed. Two code bugs sat behind it.

brand-dna.js reimplemented provider dispatch as a local switch covering 5 of
the 10 registered providers, while listProviders() advertised all 10. So it
offered gurouter, tried it, and died with `unknown_provider: gurouter` — while
every other feature used gurouter fine. It now dispatches through the registry
via runTextProvider(), one source of truth, so the two lists cannot disagree
again.

Gemini's gemini-2.5-pro returns 404 "no longer available to new users". A 404
reads as "your key is broken" when it only means the model name is gone. There
is now a model ladder with fall-through on 404; an explicit GEMINI_TEXT_MODEL
override is still honoured alone.

The wizard collapsed every failure into "couldn't read your website", which
sent people to check a URL that was fine. It now names the actual cause:
unreachable, too thin, or AI-side (quota, credits, 429, wrong model).

Adds the invariant that was broken as a test: every provider listProviders
offers must have a dispatch handler.
